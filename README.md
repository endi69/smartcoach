# SmartCoach

Mobile-first PWA per allenamento ibrido: base aerobica Z2 + ipertrofia, con alternative casa/palestra e priorità lower body/posterior chain.

## MVP
- Dashboard mobile
- Piano settimanale iniziale
- Persistenza locale di preferenze
- Manifest PWA

## Roadmap
1. Workout logger (serie/reps/carico/RPE)
2. Sostituzione esercizi casa/palestra
3. Progressione automatica
4. Storico e dashboard
5. Import/integrazione COROS
6. Installazione/deploy PWA
